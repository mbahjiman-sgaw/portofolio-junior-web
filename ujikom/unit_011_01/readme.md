# Tugas No. 11

Dokumentasi untuk project tugas ke-11 pada portofolio Junior Web.

## Tentang Project

Project ini dibuat sebagai bagian dari latihan pengembangan web. Tujuan dan fitur spesifiknya mengikuti kebutuhan tugas.

## Cara Menjalankan Project

1. Pastikan file project sudah tersedia di komputer.
2. Buka file utama project menggunakan browser atau jalankan melalui server lokal dengan node index.js atau dengan button run di pojok kanan atas dan juga dengan npm start di folder tempat index.js berada
