# Personal Website - Handito (Junior Web Programmer Portfolio)

Welcome to the repository for **Handito's Personal Profile & Portfolio Website**. This project is a simple multi-page website built with HTML5, designed to showcase basic profile information, technical skills, contact links, and sample articles.

---

## 📌 Project Overview

This website serves as a personal profile for an aspiring **Junior Web Programmer**. It features structured HTML semantics, cross-page navigation, image figures, and external links.

---

## 📁 Directory & File Structure

```text
.
├── index.html                  # Main homepage with navigation & introductory links
├── profile.html                # "Tentang Saya" page containing profile details & image
├── keahlian.html               # "Keahlian" page listing core technical skills
├── kontak.html                 # Contact page with email and social media links
```

## 🛠️ Tech Stack & Concepts Used

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<figure>`, `<footer>`)
- **Web Standards**: Accessibility features such as `meta` tags, `alt` text for images, and responsive viewport settings.
- **Hyperlinking**: Absolute and relative paths connecting multi-page document structures.
